# Stadium Performance Model

Monthly contract performance assessment for the Tātaki Auckland Unlimited natural turf maintenance contract (Go Media Stadium Mt Smart), built on the Schedule 1 Performance Model (2 November 2026), the Performance Model Calculation Sheet Draft V2 and the Technical Specification (28 October 2026). FieldTurf NZ is the sample contractor.

## What it does

- **Dashboard**: for the month chosen in the top bar, the overall score, fee paid, abatement, rectification plan test, year to date score and incentive progress; charts of the overall score and fee by month; KPI results for the month; KPI results by month (heat map); event failures and deductions for the month; Part F escalation tests; fee and band totals; Save as PDF (landscape A4 monthly report).
- **Events**: the event calendar and the joint readiness sign-off scorecard for each event. Every event-scored standard is marked Pass or Fail with an observation. Each KPI's event score updates as you go. KPI-V is only scored at the first event after renovation.
- **Monthly**: the deduction log for the month (incidents, audit breaches, late or incomplete items, monthly measured standards), confirmed by the Principal's Representative, and Part F relief (not assessed) for any KPI.
- **Bands**: the annual band reconciliation (Part E) for every band in the specification.
- **Model**: the 13 KPIs and weightings, scoring categories, score to fee table, escalation ladder and the full register of 128 performance standards with their targets and measurement methods.
- **Setup**: contractor name, contract year, last month reported, condition trends, all fee and scoring settings, KPI weightings, export to Excel, backup and restore (JSON), sample data.

Results are kept in the browser only and are not uploaded to Netlify. Use Export backup and Import backup to move them between people or computers.

## Scoring rules (same as the Calculation Sheet V2)

- Event score: each KPI with event-scored standards starts at 100 at every event and loses 20 points per failed standard (floor of zero).
- KPI result for a month: mean of the month's event scores (100 with no event) less confirmed deductions, capped at 30 points per standard. Category points: B incident 10, C audit breach 10, D late or incomplete 5, F monthly measured 10, G pilot 0.
- Overall score: weighted sum of KPI results divided by the weights of the KPIs assessed (relief reallocates a KPI's weight).
- Fee: 90 or above pays 100%; below 90 the fee reduces 1% per full point, capped at 15%.
- Rectification plan: any event failure, any critical standard failure, or two consecutive months below 90.
- Escalation: three months below 90 in any rolling six; six in any twelve. Incentive: nine months at 95 or above with improving condition trends.
- Months after the last month reported are left blank.

## Deploy to Netlify via GitHub

1. Create a private GitHub repository (for example `stadium-performance-model`) and upload the contents of this folder to it (Add file > Upload files, drag everything in, Commit). Leave out `build_model.py` and `ts.json` if you prefer; the site does not need them.
2. In Netlify: Add new site > Import an existing project > GitHub, choose the repository. No build settings are needed (`netlify.toml` publishes the folder as is).
3. Site configuration > Environment variables, add `SITE_PASSWORD` (any username works). Set this before sharing the URL.
4. Deploys > Trigger deploy so the variable takes effect. Later changes pushed to GitHub deploy automatically.

## Updating the model

`js/model.js` is generated by `build_model.py` from the Calculation Sheet V2 (Inputs, Standards Register, Band Reconciliation) and the Technical Specification standards tables (`ts.json`). Change the workbook or specification, then regenerate:

    python build_model.py "Performance Model Calculation Sheet - Draft V2 2.11.2026.xlsx" ts.json js/model.js

Weightings, thresholds and points can also be changed in Setup without regenerating.
